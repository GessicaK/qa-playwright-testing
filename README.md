# Playwright QA Testing Portfolio

## About This Project
This repository contains my hands-on practice with Playwright for software quality assurance and test automation.

## Tools and Technologies
- Playwright
- JavaScript
- Node.js

## Project Structure
- `tests/` — Playwright test scripts
- `playwright.config.js` — Playwright configuration
- `package.json` — Project dependencies and scripts
- `package-lock.json` — Dependency lock file

## How to Run the Tests
1. Install [Node.js](https://nodejs.org/).
2. Clone this repository.
3. Install project dependencies:

   `npm install`

4. Install Playwright browsers if needed:

   `npx playwright install`

5. Run the tests:

   `npx playwright test`

I am interested in functional testing, API testing, test design, and applying practical testing techniques to improve software quality.
